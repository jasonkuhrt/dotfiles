# 4-up

A 4-up presents four options for one design question
side by side. Give each option a label Jason can pick.
Use the context and content that make the choice clear.
Render the options in the conversation when the host
supports it, following its visualization guidance.
Pick buttons can send a choice to the chat when supported.
Each pick button shows only its short option label, such as
A. A caption, if present, does not repeat that label. When
the host supports it, provide a button or checkbox to mark
a pick final, so the pick sends its label and "final"
together. When a rendered 4-up can send typed text to the
conversation, it has a free-text field that can submit a
response without requiring an option label. A pick may also
include text from the field. A typed label, with "final"
when desired, works too.

- Bad: "Pick A ↗" wraps, its caption repeats "A", and a
  final pick requires typing.
- Good: "A" labels the button, its caption omits "A", and
  a final checkbox lets the pick include "final".
- Bad: the widget requires an option label, so Jason uses
  the chat composer to ask for one option's quote mark with
  another's author alignment.
- Good: the field sends that combination without a pick.

A pick without "final" starts the next round: four
variations on the choice, incorporating his requested
changes. If he asks to inspect or correct a design instead,
answer that request and keep the 4-up open. Only his "final"
ends the series.

A pick permits applying it only if the task does. When a
pick is applied for a live look, the reply that applies it
also shows the next round; it does not report the series
as done.

After final, complete and verify any implementation the
task calls for. If the choice is already applied, confirm
that rather than building it again.

Keep each active 4-up's subject, current options or their
durable location, and latest pick through compaction.

- Bad: callout A is applied and reported as finished.
- Good: callout A is applied for a live look, and the
  same reply shows four variations on it.
